# 🛠️ StockMaster - Gestão de Inventário Industrial

O **StockMaster** é uma solução para controle de estoque desenvolvida para ambientes industriais (Usinagem/Manutenção). Originalmente criado para operar com `localStorage`, o projeto evoluiu para uma arquitetura **Full Stack**, utilizando **Node.js** e **MySQL** para garantir a integridade e segurança dos dados.

## 🚀 Tecnologias Utilizadas
* **Front-End:** HTML5, CSS3, JavaScript (DOM)
* **Back-End:** Node.js, Express
* **Banco de Dados:** MySQL
* **Ferramentas:** Thunder Client, VS Code, Git/GitHub

## 📁 Como rodar o projeto
1. Clone o repositório
2. Execute `npm install`
3. Configure o banco de dados no arquivo `script.sql`
4. Use `npm start` para rodar o servidor
